# Диаграмма BPMN жизненного цикла модели

## Проект диагностики рака груди

Этот документ описывает полный жизненный цикл модели машинного обучения от бизнес-требований до архивации.

## Диаграмма процесса

```mermaid
flowchart TD
    Start([Начало: Бизнес-требование]) --> Define[Определить цель]
    Define --> Feasibility{Экономическая целесообразность?}
    Feasibility -->|Нет| Reject([Отклонить проект])
    Feasibility -->|Да| Collect[Собрать данные]
    Collect --> Preprocess[Предобработка]
    Preprocess --> Split[Разделить данные]
    Split --> Train[Обучить модели]
    Train --> Evaluate[Оценить]
    Evaluate --> Compare{Точность > 95%?}
    Compare -->|Нет| Experiment[Настройка и эксперименты]
    Experiment --> Train
    Compare -->|Да| Validate{Валидация?}
    Validate -->|Нет| Experiment
    Validate -->|Да| Register[Регистрация модели]
    Register --> Deploy[Развёртывание]
    Deploy --> ABTest[A/B тест]
    ABTest --> ABDecision{Новая модель лучше?}
    ABDecision -->|Нет| Rollback[Откат к старой модели]
    ABDecision -->|Да| Production[Продакшн]
    Rollback --> Monitor
    Production --> Monitor[Мониторинг модели]
    Monitor --> Drift{Обнаружен дрейф?}
    Drift -->|Нет| Production
    Drift -->|Да| Alert[Оповещение]
    Alert --> Retrain[Переобучение]
    Retrain --> ReEvaluate[Повторная оценка]
    ReEvaluate --> Better{Качество улучшилось?}
    Better -->|Нет| HumanReview[Ручная проверка]
    HumanReview --> Experiment
    Better -->|Да| Redeploy[Развёртывание новой версии]
    Redeploy --> Production
    Production --> Archive{Модель устарела?}
    Archive -->|Нет| Production
    Archive -->|Да| ArchiveModel[Архивация модели]
    ArchiveModel --> End([Конец: Модель заархивирована])

Этапы
1. Бизнес-требования

    Определить цель: диагностика рака груди

    Оценить экономическую целесообразность

    Установить KPI (точность > 95%, recall > 95%)

2. Сбор данных

    Источник: Wisconsin Breast Cancer Dataset

    Размер: 569 образцов, 30 признаков

    Классы: доброкачественные (357), злокачественные (212)

3. Предобработка

    Проверка пропущенных значений

    Удаление выбросов методом IQR

    Масштабирование StandardScaler

    Опционально: PCA и Fuzzy C-Means

4. Обучение моделей

    Обучение 4 моделей: Decision Tree, Naive Bayes, Perceptron, KNN

    Настройка гиперпараметров

    Кросс-валидация

5. Оценка

    Метрики: Accuracy, Precision, Recall, F1, AUC-ROC

    Анализ матрицы ошибок

    Лучшая модель: Perceptron с точностью 97.37%

6. Валидация и утверждение

    Проверка бизнес-заказчиком

    Создание Model Card

    Проверка соответствия

7. Регистрация модели

    Сохранение весов модели (pkl.)

    Логирование метаданных (версия, дата, метрики)

    Регистрация в Model Registry

8. Развёртывание

    API на FastAPI

    Контейнеризация через Docker

    Оркестрация через Kubernetes (опционально)

9. A/B тестирование

    Сравнение новой модели со старой

    Разделение трафика (50/50)

    Мониторинг реальных метрик

10. Мониторинг в продакшне

    Обнаружение дрейфа данных

    Обнаружение дрейфа концепции

    Отслеживание бизнес-метрик

    Мониторинг SLI/SLO

11. Переобучение (автоматическое)

    Триггер: обнаружен дрейф

    Пайплайн: Сбор → Предобработка → Обучение → Оценка

    Автоматическое развёртывание при улучшении

12. Архивация

    Когда: модель устарела

    Что: веса + метаданные + ссылки на данные

    Почему: юридическое соответствие, возможность отката

Роли

    Дата-сайентист: обучение, оценка, переобучение

    ML-инженер: регистрация, развёртывание, мониторинг

    Бизнес-владелец: требования, валидация

    Комплаенс: проверка регуляций, архивация

Триггеры автоматизации

    Дрейф данных (PSI > 0.2): оповещение + переобучение

    Падение производительности (точность < 95%): переобучение

    Расписание (ежедневно 02:00): переобучение при новых данных

    Объём новых данных (> 1000 образцов): переобучение

    Вручную: запрос дата-сайентиста

Инструменты

    Сбор данных: pandas

    Предобработка: scikit-learn, numpy

    Обучение: scikit-learn, joblib

    Оценка: scikit-learn metrics

    Развёртывание: FastAPI, uvicorn, Docker

    Мониторинг: Prometheus, Grafana

    CI/CD: GitHub Actions, pre-commit

Версионирование модели

    Версия 1.0.0 (1 сентября 2026): первая версия, точность 92%

    Версия 2.0.0 (29 сентября 2026): Perceptron, точность 97.37% (текущая)

## О модели

Модель классифицирует опухоли груди как доброкачественные или злокачественные по 30 числовым признакам из изображений FNA. Основная модель — Перцептрон, обученный на датасете Wisconsin Breast Cancer. Три другие модели (Decision Tree, Naive Bayes, KNN) доступны через API для сравнения.

## Применение

### Основное применение

- **Пользователи:** медицинские специалисты, исследователи, дата-сайентисты
- **Цель:** поддержка предварительной диагностики рака груди
- **Роль:** только поддержка принятия решений, не окончательный диагноз

### Применение вне области

- Не для окончательного диагноза без подтверждения патолога
- Не для данных с другим распределением признаков
- Не для мужчин или детей (датасет содержит только женщин)
- Не для критических решений без участия человека

## Факторы

- 30 признаков ядер клеток: radius, texture, perimeter, area, smoothness, compactness, concavity, concave points, symmetry, fractal dimension (mean, SE, worst)
- Источник данных: Wisconsin Breast Cancer Dataset
- Количество образцов: 569 (357 доброкачественных, 212 злокачественных)
- Масштабирование: StandardScaler

## Ограничения

1. Обучена на одном датасете; может не обобщаться на другие популяции
2. Требует все 30 признаков
3. Распределение классов несбалансированное
4. Перцептрон не даёт вероятностей
